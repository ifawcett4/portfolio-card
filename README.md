# Irina Fawcett — Portfolio

Personal portfolio showcasing selected creative technology, immersive, and augmented reality projects.

**Live site:** [www.irinafawcett.xyz](https://www.irinafawcett.xyz)

## Local development

```bash
npm install
npm start
```

The development server runs at [http://localhost:3000](http://localhost:3000).

Create a production build with:

```bash
npm run build
```

## Built with

- React
- Three.js and React Three Fiber
- Sass
